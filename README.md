I build and evaluate intelligent software systems, from scratch-trained diffusion models and computer-vision applications to a C-to-JavaScript transpiler. My co-authored publications include research on sustainable agri-food systems, IoT, and data traceability. My focus is on reproducible experiments, testable implementations, and transparent evaluation limits.

**Education.** BSc in Computer Engineering and Automation, *110/110 cum laude* (23 October 2024), Politecnico di Bari. Currently pursuing an MSc in Computer Engineering (Data Science & AI curriculum). [Education profile on LinkedIn](https://www.linkedin.com/in/bartolo-morgigno/).

## Featured work

### [Tiny Avatar Diffusion](https://github.com/BartoloMorgigno11/tiny-avatar-diffusion)

<a href="https://github.com/BartoloMorgigno11/tiny-avatar-diffusion"><img src="https://raw.githubusercontent.com/BartoloMorgigno11/tiny-avatar-diffusion/master/docs/images/streamlit-conditional-demo.png" alt="Streamlit demonstration of the Tiny Avatar Diffusion conditional model" width="400" /></a>

**Generative AI · DDPM · PyTorch · Streamlit**

A compact diffusion project with four integrity-checked inference checkpoints, frozen experimental evidence, a CPU verification path, and automated checks. The repository documents what the models do and the boundaries of the evaluation.

### [Olive Ripeness Detection](https://github.com/BartoloMorgigno11/Olive-detection-using-CNN-models-based-on-fine-tuned-YOLOv8)

<a href="https://github.com/BartoloMorgigno11/Olive-detection-using-CNN-models-based-on-fine-tuned-YOLOv8"><img src="https://raw.githubusercontent.com/BartoloMorgigno11/Olive-detection-using-CNN-models-based-on-fine-tuned-YOLOv8/main/docs/images/upload-screen.png" alt="Olive Ripeness Detection interface for uploading images for analysis" width="400" /></a>

**Computer vision · YOLOv8 · Flask · React**

A full-stack olive-fruit detection prototype built around a fine-tuned YOLOv8 detector, Flask API, and React interface. Real execution requires the separately provided model weights; geometric estimates are experimental image-space proxies, not calibrated physical measurements.

### [NLP Sentiment Analysis](https://github.com/BartoloMorgigno11/1st-Place-AI-Hackathon---NLP-Sentiment-Analysis)

**NLP · TF-IDF · Logistic regression · Evaluation**

Sentiment-analysis solution developed for the Randstad & MKERS hackathon, using TF-IDF and class-balanced logistic regression. The winning team is documented in the [organiser's public announcement and participant post](https://it.linkedin.com/posts/bartolo-morgigno_grazie-mille-per-la-bellissima-esperienza-activity-7262877376995328000-8j8m). The public repository includes synthetic-data CI checks; original competition reviews are not redistributed.

### [C to JavaScript Transpiler](https://github.com/BartoloMorgigno11/C-to-JavaScript-Transpiler)

**Compilers · Flex/Bison · C · Python · Flask**

An experimental C-subset transpiler with a Flex/Bison front end, semantic checks, Python code generation, automated regression tests, and Ubuntu CI verification. It intentionally supports only the documented subset of C, not ISO C in general.
