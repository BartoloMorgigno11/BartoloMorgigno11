## Featured work

### [Tiny Avatar Diffusion](https://github.com/BartoloMorgigno11/tiny-avatar-diffusion)

<a href="https://github.com/BartoloMorgigno11/tiny-avatar-diffusion"><img src="https://raw.githubusercontent.com/BartoloMorgigno11/tiny-avatar-diffusion/master/docs/report/figures/final_four_model_unconditional_gallery.png" alt="Samples from the four Tiny Avatar Diffusion inference models" width="720" /></a>

**Generative AI · DDPM · PyTorch · Streamlit**

A compact diffusion project with four authenticated inference checkpoints, frozen experimental evidence, a CPU verification path, and automated checks. The repository documents what the models do and the boundaries of the evaluation.

### [Olive Ripeness Detection](https://github.com/BartoloMorgigno11/Olive-detection-using-CNN-models-based-on-fine-tuned-YOLOv8)

<a href="https://github.com/BartoloMorgigno11/Olive-detection-using-CNN-models-based-on-fine-tuned-YOLOv8"><img src="https://raw.githubusercontent.com/BartoloMorgigno11/Olive-detection-using-CNN-models-based-on-fine-tuned-YOLOv8/main/docs/images/analysis-results.png" alt="Olive ripeness-detection analysis results" width="720" /></a>

**Computer vision · YOLOv8 · Flask · React**

An end-to-end olive-fruit detection prototype: a fine-tuned YOLOv8 detector, a Flask API, a React interface, and documented training, setup, and limitations.

### [NLP Sentiment Analysis](https://github.com/BartoloMorgigno11/1st-Place-AI-Hackathon---NLP-Sentiment-Analysis)

**NLP · TF-IDF · Logistic regression · Evaluation**

Winning sentiment-analysis solution based on a reproducible TF-IDF and class-balanced logistic-regression pipeline for hotel reviews.

### [C to JavaScript Transpiler](https://github.com/BartoloMorgigno11/C-to-JavaScript-Transpiler)

**Compilers · Flex/Bison · C · Python · Flask**

A compiler-oriented project with lexical and syntactic analysis, semantic checks, Python code generation, tests, and a small Flask interface.
